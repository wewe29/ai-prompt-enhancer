# 新手使用指南（小白版）

这篇文章用最啰嗦的方式，一步步带你跑通「提示词增强效果评测」。你不需要懂编程，只需要会**复制粘贴命令**和**点鼠标**。

> 时间预估：第一次（含登录）约 15~30 分钟；以后每次跑评测约 10~30 分钟（取决于网页回答速度）。

---

## 零、先理解这是干什么的

这个脚本在做一件很直观的事：

1. 准备 **10 条测试问题**（比如"帮我修一段有 bug 的代码"）
2. 每条问题先用「提示词增强器」改写成更规范的版本（**增强后**）
3. 把「**原始版**」和「**增强版**」分别发给 豆包 / DeepSeek 网页版，让它们各回答一次
4. 用 AI 裁判对同一问题的两组回答打分：准确性、完整性、相关性、清晰度
5. 生成一份报告，告诉你**增强到底有没有用、好在哪**

你全程只需要做：**登录一次 + 敲一条命令 + 打开一个文件**。

## 一、准备工作（检查环境，约 2 分钟）

下面的命令只要在**第一次**使用时跑一次。如果之前已经装好，可以跳过。

### 1. 打开"命令窗口"（PowerShell）

- 按键盘左下角的 **Windows 键**（四个小方块）
- 直接输入 `powershell`
- 按**回车**，会弹出黑色/蓝色的窗口

> 后面所有以 `> ` 开头的代码，都是要在这个窗口里输入的内容。

### 2. 进入评测脚本所在的文件夹

把下面这行**完整复制**，粘贴进窗口（右键粘贴，或 Ctrl+V），然后按回车：

```powershell
cd D:\codex_home\03_项目目录\ai-prompt-enhancer\evaluation
```

> 这一步是让命令窗口"走到"脚本所在的位置。输完这行后，窗口里出现的下一行路径应该变成 `...\evaluation>`，就说明进来了。

### 3. 安装依赖（只用装一次）

复制这一整段，粘贴后按回车，**等它跑完**（看到 `Successfully installed ...` 就是成功）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

> 说明：
> - 脚本默认使用**系统自带的微软 Edge**（`browser.channel: msedge`），**不装浏览器也能跑**；
> - 第二条命令下载的 Chromium 只在你想改用 `chromium` 通道时才需要，**装不了也不影响**用 Edge。
> - 如果报 `__dirlock` / safe-delete 之类的错，多半是上次没装完，把命令**再运行一遍**即可。

## 二、登录网页版（只做这一次，约 5 分钟）

复制这行命令，粘贴、回车：

```powershell
.\.venv\Scripts\python.exe run_eval.py --login
```

会发生什么：

1. 屏幕上**自动弹出一个浏览器窗口**（这是**微软 Edge** 浏览器——脚本默认用系统自带的 Edge，不会另装浏览器）
2. 它会先打开**豆包**——你在窗口里**扫码或输账号登录**（和平时登录网页一样）
3. 登录完成后，**回到命令窗口按一下回车**，它再去打开 **DeepSeek 网页版**
4. 同样登录完，再按回车……直到提示"登录完成"
5. 登录状态会保存下来，**以后不用再登录**

> 小提示：
> - 如果某个网站你本来就不想测，也可以跳过（在窗口里多按几次回车）。
> - 登录时如果遇到滑块验证码，**手动拖一下**就行，这不影响脚本。

## 三、开始评测（每次只需一条命令）

登录完成后，输入：

```powershell
.\.venv\Scripts\python.exe run_eval.py
```

然后**耐心等**，会发生这些事（都在自动进行，你不需要操作）：

- 命令窗口会一行行滚动：先是 `[增强]`（改造提示词），然后是每个网站的回答进度 `[样本id][原始/增强] 完成（xxx 字符）`
- 弹出来的浏览器窗口会**自己输入文字、自己点发送、自己复制回答**——**别去动它**，也别在窗口里点别的
- 全部跑完后，窗口最后会打印：

```
报告目录：D:\...\evaluation\results\2026-08-08_113413
  - report.md / report.html / summary.json / raw/
```

这就成功了。

> ⏱ 建议评测期间不要用网盘下载大文件、不要看高清视频，避免回答变慢。

## 四、看结果（打开报告）

1. 在**文件管理器**（文件夹窗口）里，打开：
   `D:\codex_home\03_项目目录\ai-prompt-enhancer\evaluation\results`
2. 里面会有一个以**时间命名的文件夹**（比如 `2026-08-08_113413`）
3. **双击 `report.html`**（用浏览器打开，最好看，支持折叠展开）
   - 顶部：整体结论卡片（"增强后更优 X%""胜/平/负"）
   - 中间：按维度/场景/模型的汇总表
   - 下面：每条问题的详情（原始提示词、增强后提示词、两个网站的回答、打分对比）
4. 想用记事本看文字版，就打开同目录的 `report.md`

## 五、常用小命令（按需使用）

| 我想…… | 输入的命令 |
|---|---|
| 重新登录网页版 | `.\.venv\Scripts\python.exe run_eval.py --login` |
| 只测豆包一个网站 | `.\.venv\Scripts\python.exe run_eval.py --target doubao` |
| 只测 DeepSeek 网页版 | `.\.venv\Scripts\python.exe run_eval.py --target deepseek_web` |
| 上次跑到一半断了，接着跑（不重复扣费） | `.\.venv\Scripts\python.exe run_eval.py --skip-enhance --skip-infer` |
| 只想看看报告长什么样（不联网演示） | `.\.venv\Scripts\python.exe run_eval.py --offline` |

> `--target` 后面跟的名字，就是 `config.yaml` 里 `targets:` 下面第一层的名字（如 `doubao`、`deepseek_web`、`qwen`）。

## 七、常见问题（先看这里再求助）

**Q1：提示"未找到输入框，可能是未登录或页面改版"**
→ 先跑 `--login` 重新登录；登录后还报错，大概率是该网站改版了，把 `config.yaml` 里对应 `selectors` 告诉我，我帮你改。

**Q2：提示"未找到 DeepSeek API Key"**
→ 检查环境变量 `DEEPSEEK_API_KEY` 是否设置。也可以直接在 `config.yaml` 最上方把 `key_source` 改成 `config`，并在下面 `api_key:` 填上你的 Key。

**Q3：命令窗口报错看不懂**
→ 没关系，把**报错的那几行**复制发给我（或截个图），我来处理。

**Q4：浏览器窗口自己打字、自己点，正常吗？**
→ 完全正常，这就是自动化在干活。**别碰那个窗口**，等它自己停。

**Q4.5：登录时浏览器停在 about:blank / 空白页，不跳转？**
→ 这是旧版本的一个 bug（登录模式没有自动跳转网址），已修复。请重新运行 `--login`，
窗口会自动打开豆包/DeepSeek 页面；如果仍空白，可以**在浏览器地址栏手动输入**站点网址后登录。

**Q5：想换一批测试问题？**
→ 编辑 `evaluation\samples\samples.yaml`，照着里面的格式加/改问题即可。

**Q6：网页版回答很慢 / 卡住不动**
→ 正常，网页版就是慢。超过 5 分钟没动，可以 Ctrl+C 停掉，然后用 `--skip-enhance --skip-infer` 接着跑（已完成的会跳过）。

## 八、目录里都是啥（认识一下）

```
evaluation/
├── run_eval.py          ← 主程序（你要运行的就是它）
├── config.yaml          ← 设置（网站开关、选择器、预算）——小白不用动
├── samples/samples.yaml ← 测试问题清单 —— 想换问题就改它
├── .browser_profile/    ← 网页版登录状态（别删，删了要重新登录）
├── results/             ← 评测报告都在这（每次一个时间文件夹）
└── .venv/               ← 运行环境（别删）
```

**黄金法则：`.venv`、`.browser_profile`、`results` 这三个文件夹都不要手动删除。**

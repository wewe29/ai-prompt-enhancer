PromptCraft 0.1.0 - Windows 10/11 64 位便携版

使用方法：
1. 解压完整 ZIP，双击 PromptCraft.exe。
2. 首次运行可能出现 Windows SmartScreen 提示，因为当前版本没有代码签名。
3. 软件不要求 Python、Node.js 或开发工具。
4. 如果系统缺少 WebView2，软件会调用同目录的微软官方引导程序静默安装；这一步需要联网。
5. API Key 保存在 Windows 凭据管理器，数据库和设置保存在当前 Windows 用户的应用数据目录。

隐私与数据：
- 提示词增强内容会发送到你配置的 DeepSeek API。
- 附件仅在本机提取文本，原文件不会复制到应用目录。
- 导出包不包含 API Key、附件原件或操作日志，但可能包含敏感提示词，请妥善保管。
- “彻底清空”会删除应用数据库、设置和凭据，但受 SSD 磨损均衡机制影响，无法保证底层数据绝对不可恢复。

费用：
- API 费用由你的 DeepSeek 账户承担，软件内费用为按配置价格计算的估算值。

# v0.4.2 测量证据归档

本目录登记 v0.4.2 效果线的测量证据。

## 当前状态

| 阶段 | 内容 | 状态 |
|---|---|---|
| **A（可达性核算）** | 用 v2.5.0 跑 60 条，统计各门槛需要的分母与实测分母的差距 | ✅ 已归档 |
| B（人工盲评 + 效果线） | 门槛 4/5 的真人盲评、门槛 6 的计数、装配 `v040_gates` | ⬜ 未开始 |

## 纪律

1. **本目录的数字不是效果指标。** 阶段 A 回答的是「还差多少」，
   不是「做到了多少」。阶段 A 的数字**不得**出现在任何效果宣称里。
2. **结论与复现材料必须同版本。** 提示词正文参与运行身份哈希
   （`prompt_sha256`），v2.2.0 时期的数据（`docs/evaluation-data-v040/`）
   与本目录**不可直接比较、不可混跑**。
3. **人工盲评答案必须脱敏后归档**（`answers/`），
   并在 `manifest.json` 登记：文件名、用途、评审人数、单元数、sha256。
4. **不得用 AI 代替真人做「人工盲评」** —— 那会让这个词本身变成谎报。
5. 单评审者时，结论里必须写明「轮间与人间方差未分离」。

## 目录

## 二、总体结果

- 有效对比（(样本×目标) 中至少 1 个完整 rep 已裁判）：**222 / 240 组**
- 胜负关系（主对比 A=原始 vs C=增强，按 rep 聚合）：**胜 143 / 平 38 / 负 41**（胜率 64.4%，Wilson 95% CI [57.9%, 70.4%]，单侧二项 p<0.0001）
- 五维平均 Delta（增强 − 原始，裁判聚合）：准确性 **+0.47**｜完整性 **+0.85**｜相关性 **+0.56**｜清晰度 **+0.35**｜新颖度 +0.18
- 其中「明显更优」（任一维度 +2 以上）：59 组（26.6%）
- 增强器 API 预估成本：$3.35（含全部补跑与裁判调用）

> ⚠️ 以上自动裁判口径的胜率与 Delta 未通过发布门槛（§七），且被人工盲评证伪其方向（§五），不可用作产品效果数字。

## 三、双裁判一致性

- 主裁判（deepseek-v4-flash）vs 第二裁判（glm-5.2）胜者一致率：**67.6%**（n=222）——低于 75% 门槛，未通过（v0.3.0 基准为 62.7%）。
- 四维分数相关（Spearman ρ）：0.495——两裁判对「哪边更好」分歧明显。

## 五、人工盲评结果（48/222 ≈ 21.6%，发布门槛必要项）

- 抽样：按 目标×难度 分层，每目标 12 个单元（clear/medium/severe 各约 4 个），固定 seed=42 可复现；评审者盲态下仅见匿名回答 A/B（随机顺序），评审完成后揭盲。

## 八、结论与建议（定性，用于 README）

1. **量化提升数字不可用**：自动裁判口径的胜率（64.4%）与 Delta 被削弱——双裁判一致率不足（67.6% < 75%）、人工盲评与自动的一致度过低（修正后 53.8%，κ 0.152，属弱一致）。根本原因是 LLM-as-judge 对更长、结构化更强的回答存在系统性打分偏好，而增强回答恰好更长更结构化（膨胀 ×4.63）。
   > *v0.4.0 更正：原文此处写「人工盲评方向相反」，成因是 §五 的揭盲大小写缺陷；修正后为「方向一致但强度弱」。结论（数字不可用）不变，依据由「方向相反」改为「一致度过低」。*
2. **盲态人工对比不支持「增强带来质量优势」**：48 个盲评单元中 **10 个判增强组更好（20.8%）、17 个判原文更好（35.4%）、21 个判接近（43.8%）**；三个难度层分别为 clear 4/4/8、medium 3/6/7、severe 3/7/6，胜率均落在 19%–25% 这个「接近偶然」的水平上。**没有任何一档显示增强占优的证据**，但也**不能说人工全面否定增强**——clear 档 25% 胜率的 bootstrap 95% CI 为 [6.2%, 50.0%]，与 0% 不可区分。因此连此前「严重模糊任务通常受益」的定性表述也应弱化为：对信息严重缺失的任务，增强回答在覆盖面上更完整，但不保证质量更优，需逐项审核后采用。
   > *v0.4.0 更正：原文此处写「0 个判增强组更好、56.3% 判原文更好」，为 §五 揭盲大小写缺陷所致，已作废。*
3. **清晰任务不应使用增强**：自动口径清晰任务变差率 41.1%（自动裁判口径独立于 §五 缺陷，不受影响）；人工盲评清晰层 4/16 判增强更好、4/16 判原文更好、8/16 平——**人工侧不构成「清晰任务增强更好」的反证，而是「无差别」**。两个口径合起来仍指向「已写清楚的任务优先保留原文」：自动口径说增强会变差，人工口径说增强也换不来好处。
   > *v0.4.0 更正：原文此处写「8/16 判原文更好、0 判增强更好」，为 §五 缺陷所致，已作废。*
4. **对清晰任务的回退保护是真实需求**：这是 v0.3.3「增强结果体验」（增强必要性判断、逐项接受/拒绝、恢复原文）的直接依据；门槛未达不阻塞后续体验类迭代，但任何量化效果宣称继续禁止。
5. **评测设施**：plan 端点 glm 系部署的长思考（>16k token / >8 分钟）导致 9.9% rep 单元不可恢复地缺失，属目标侧限制；后续评测若继续使用 glm 系目标，需将 max_tokens 与超时预算纳入协议并如实报告覆盖率。

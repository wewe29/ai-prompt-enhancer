## 一、为什么需要这份规范（问题的来源）

`docs/PromptCraft-v0.4.0-iteration-spec.md` §7 的 7 条门槛里，有 3 条作用在
**有运行间噪声的比率型指标**上，而它们的问题不是"阈值定得不对"，是**阈值与噪声的关系**：

| 事实 | 出处 |
|---|---|
| 同一配置的两次独立运行给出 **30% 与 71%**，噪声地板约 **41 个百分点** | `docs/PromptCraft-v0.4.0-效果验证报告.md` §5.2；`docs/PromptCraft-v0.4.0-iteration-spec.md` §10.2 |
| 门槛 1 目标 ≤30% —— **恰等于两次运行中较好的一次** | `docs/PromptCraft-v0.4.0-iteration-spec.md` §7 |
| 门槛 1/2/3 的间距分别是 **25 / 3 / 10 个百分点** | 同上 |

⇒ **把门槛定在"同配置多跑里较好的一次"上，重跑时该门槛约等于掷硬币。**
⇒ 更根本的：**间距小于噪声地板时，增加样本数与运行轮次都不能把两个水平分开。**

本规范把这两件事变成可计算的东西，并规定**门禁只有 PASS / FAIL 两种输出**。

## 二、判定模型（唯一的一套）

### 2.1 噪声分解

观测比率 `p̂` 的方差分两项：

```
Var(p̂) = p(1-p)/n  +  τ²/R
          ↑二项噪声      ↑运行间漂移
```

- `n` = 每轮参与比较的提示词条数
- `R` = **独立运行轮数**
- `τ` = 运行间标准差（**每个门槛自己的**，见 §3.2）

`n` 压二项项，`R` 压运行间项。**加 `n` 压不掉 `τ`。**

### 2.2 可判定条件

设门槛间距 `Δ = |现状 − 目标|`，噪声半宽

```
h = z(1-α/2) · √( p̄(1-p̄)/n + τ²/R )
```

门槛**可判定** ⟺ `h ≤ Δ/2`（否则区间会跨过阈值，结论会翻转）。

由此解出两个要求：

```
需 n（区分现状与目标，纯二项口径）:
    n = [ z(1-α)·√(p_bad(1-p_bad)) + z(1-β)·√(p_good(1-p_good)) ]² / (p_bad − p_good)²

需 R（给定 n 时）:
    R ≥ τ² / ( (Δ/(2·z(1-α/2)))² − p̄(1-p̄)/n )

需 n（给定 R 时）:
    n ≥ p̄(1-p̄) / ( (Δ/(2·z(1-α/2)))² − τ²/R )
```

α=0.05（单侧），β=0.20。

### 2.3 判定规则（输出只有 PASS / FAIL）

比率型门槛（`direction` 为 `<=` 或 `>=`）：

```
PASS ⟺ p̂ ± h 完全落在达标侧        （取最坏情况也达标）
FAIL ⟺ p̂ ± h 完全落在不达标侧      （取最好情况也不达标）
FAIL ⟺ 区间跨越阈值                 （不可判定 —— fail-closed）
```

> **"不可判定"是 FAIL 的原因标签，不是第三种输出。**
> 缺数据、缺分母、缺运行轮次，一律 FAIL。理由见 `docs/v040-缺失语义约定.md` R3。

### 2.4 计数型门槛

`0 命中` 只能证到有限精度：**0 事件在 n 次试验下的 95% 率上界 ≈ 3/n**。
要把真实率证到 ≤5%，需要 `n ≥ 3/0.05 = 60`（取 61）。

## 三、逐条门槛的要求（全部由代码推导，不手写）

### 3.1 总表

来源：`python evaluation/gate_spec_report.py`

| id | 门槛 | 现状 | 目标 | 间距 | τ | 需 n（区分） | 需 R | 状态 | 可判定性 |
|---|---|---|---|---|---|---|---|---|---|
| G1 | clear 档 none/light 跨点击翻转率 | 55% | ≤30% | 25pt | 0.41 | 24 | 不可行 | **作废** | R=50 时 n≥347；即使 n→∞ 也需 **R≥42** |
| G2 | medium 档 none/light 跨点击翻转率 | 33% | ≤30% | 3pt | 0.41 | 1493 | 不可行 | **作废** | R=3000 时 n≥85013；n→∞ 仍需 **R≥2870** |
| G3 | clear 档 light 出现率（防功能死） | 52% | ≥42% | 10pt | 0.41 | 154 | 不可行 | **作废** | R=500 时 n≥792；n→∞ 仍需 **R≥259** |
| G4 | 翻译场景人工盲评命中率 | 11% | ≥60% | 49pt | 0 | 5 | 2 | 生效 | R=1 时 n≥15 |
| G5 | severe 档整体人工盲评命中率 | 73.3% | ≥85% | 12pt | 0 | 68 | 2 | 生效 | R=1 时 n≥186 |
| G6 | 严重档「问已知信息」条数 | 2/20 条 | 0 条 | — | 0 | 61 | 1 | 生效 | 计数型：n≥61 才能把真实率证到 ≤5% |
| G7 | 交付状态漂移 | 0/360 次 | 0 次 | — | 0 | 61 | 1 | 生效 | 计数型：当前 360 次已远超要求 |

**读法**：
- 「需 n（区分）」= 把现状水平与目标水平分开所需的条数（纯二项口径）。
- 「需 R」= 在该 n 下让噪声半宽 ≤ 间距/2 所需的独立运行轮数；**不可行** = 再加轮次也补不回来（二项项本身已超过预算）。
- 「R=X 时 n≥Y」= 把轮次提到 X 时，所需的条数。

### 3.2 τ 不可跨门槛套用

| 噪声模型 | τ | 来源 | 适用 |
|---|---|---|---|
| `run_to_run` | 0.41 | 同配置两次独立运行 30% vs 71%（`docs/PromptCraft-v0.4.0-效果验证报告.md` §5.2） | **只适用于模型档位决策类门槛**（G1–G3） |
| `binomial` | 0 | 尚无实测的评审者间/轮间方差（效果验证报告 §五.3 自述「1 名评审者、20 条、单轮」） | 人工盲评类（G4–G7） |

> **41 个百分点是模型决策的运行间漂移，不是人工评审的漂移。**
> 把 τ=0.41 套到人工门槛上是错的；反过来，把 τ=0 套到模型门槛上也是错的。
> 人工门槛用纯二项是**乐观**的（真实区间被低估），因此规范要求它们 **R≥2 轮独立评审**，
> 以便把轮间方差暴露出来 —— 但轮间方差本身仍需实测后替换本模型（**已知限制，未闭环**）。

### 3.3 为什么 G1–G3 被作废而不是"调阈值"

Chief 已决断作废门槛 1/2/3（重建基线）。本规范给出的**量化理由**是：

- **G1**：目标 ≤30% 恰等于两次运行中较好的一次 ⇒ 阈值本身是噪声的产物。
  即使不看这一点，间距 25pt 与噪声 41pt 相比，要求 R≥42 轮独立运行才可判定。
- **G2**：间距 3pt。需要 R≥2870 轮 —— 实务上不可行。
- **G3**：间距 10pt。需要 R≥259 轮 —— 实务上不可行。

> **门槛本身的方向是对的**（G3 防的正是 v2.3.0「功能死」那个失败），
> 不该丢；该丢的是**当前这组数值**。重建基线后必须用 §3.1 的推导重新定阈值。

**重建要求**（写进规范文件，供后续轮次直接引用）：
1. 用交错设计重建基线（两臂在**同一轮**内交错执行，见 `docs/v040-效果测量方案.md` §3.4）；
2. 阈值设在**重建基线的单侧上置信界之外**，而不是"最好一次"的值上；
3. 翻转率与 light 出现率**一起测**（双指标联立），否则无法区分"判得更准"与"什么都不做"。

## 四、分母流失怎么判

### 4.1 规则

> **应有（expected）与实有（judged）必须同时落在产物里；流失比例低于 95% ⇒ FAIL。**

`report.py` 的 `_aggregate()` 现在产出（`summary.comparison`）：

| 字段 | 含义 |
|---|---|
| `expected_total` | 应有多少次比较（样本数 × 目标数） |
| `attempted_total` | 实际发起了多少次比较 |
| `judged_total` | 拿到裁判结果多少次（= `summary.total`） |
| `excluded.no_result` | 应有但连尝试都没有的（目标站点登录失败等整段跳过） |
| `excluded.judge_failed` | 尝试了但没有裁判结果的 |
| `coverage_rate` | `judged_total / expected_total` |
| `win_rate_of_expected` | 保守口径：把流失的比较算作"没赢" |

### 4.2 为什么必须显式化

清单 A6（`docs/v040-失败伪装清单.json`）记录的原机制是
`report.py` 里 `if not judge: continue` —— 裁判失败的样本静默退出分母。
后果：**样本流失越多，胜率/一致率/变差率越好看**（"失败得越彻底，指标越漂亮"）。

现在这条链路被三处堵住：
1. 聚合层：排除数与原因落进产物（`summary.comparison.excluded`）；
2. 判定层：`release_gate.py` 的「比较样本完整性（实有/应有 ≥ 95%）」门槛，流失 ⇒ FAIL；
3. 呈现层：报告里同时显示"应有 N 组 / 已尝试 N 组 / 已排除：judge_failed=M"。

### 4.3 判定的具体阈值

| 情况 | 判定 |
|---|---|
| `expected_total` / `judged_total` 缺失 | **FAIL**（缺失，fail-closed） |
| `coverage_rate < 0.95` | **FAIL** |
| `coverage_rate ≥ 0.95` 且排除原因已留痕 | PASS |

**不允许有"不可判定"混过去**：分母不够就判 FAIL，不放行。

## 五、同配置跑几次、取什么统计量、单次运行的结果能不能进结论

### 5.1 结论先给

| 问题 | 答案 |
|---|---|
| 同配置跑几次？ | 由 `Δ` 与 `τ` 决定，见 §3.1 的「需 R」列。**模型决策类门槛当前全部不可行**；人工类门槛最少 **2 轮独立评审**。 |
| 取什么统计量？ | **合并多轮后的池化比率** `p̂ = Σ(各轮命中) / Σ(各轮样本数)`，**不是**各轮比率的简单平均。 |
| 单次运行的结果能不能进结论？ | **不能。** 任何比率型门槛，`R=1` 一律 FAIL（`decide_rate` 在 `runs` 缺失或 < `required_runs` 时直接判 FAIL）。 |
| 计数型门槛（0 命中）呢？ | 可以进结论，但只能证到 `3/n` 的精度。G6 当前 n=20 ⇒ 只能证"真实率 ≤15%"，**证不到 ≤5%**。 |

### 5.2 池化而不是平均

各轮比率平均会给小轮次同等权重，且忽略轮次的样本量差异。**必须用合并计数**：
把 R 轮的命中数与样本数分别累加再相除。这样 `n` 自然变成 `Σn_r`。

### 5.3 独立轮次的定义

"独立运行轮次"必须是**独立的一轮完整实验**，满足：
- 新的进程/会话，**不复用上一轮的缓存**（缓存键必须含身份 —— 清单 D3，仍未闭环）；
- 产物目录独立（`evaluation/run_identity.py` 已提供带身份标签的目录命名）；
- 两臂在**同一轮内交错**执行，让轮级项在差分里相消。

### 5.4 为什么"交错"是关键

若两臂在**不同轮**执行，轮级项 `τ` 不相消，`Var(差) = 2(p(1-p)/n + τ²/R)`，
此时 `n → ∞` 也压不掉 `τ`。交错是唯一能把它消掉的设计。

## 八、本规范**没有**解决的事（诚实边界）

1. **τ=0.41 只由 2 个观测估计**（30% 与 71%），只能当量级，且是噪声地板的**下界**估计 ——
   真实方差可能更大。可判定性结论因此是**乐观**的。
2. **人工评审的轮间方差从未实测**。G4–G7 现在按纯二项处理（乐观），
   且 `min_runs=2` 只是把方差暴露出来，没有把它建模进去。
3. **G1–G3 的重建基线尚未跑**。本规范只给出"重建需要什么条件"，没给重建后的数值 ——
   那需要 Chief 已批准的 $0.30 双跑交错诊断实验（140 次调用，硬上限 $1）。
4. **G6 当前只有 20 条 severe 样本**，只能证"真实率 ≤15%"，证不到 ≤5%。
   要证到 ≤5% 需要 61 条 severe 样本 —— 样本集当前没有。
5. **清单 A6 的复核器探针仍报 OPEN**：`scripts/check-fail-open.py` 探的是
   `if not judge:` 这个**字符串**，而 A6 的行为级闭环（排除计数 + 分母门槛 + 行为回归测试）
   是它看不见的。这正是它自己 README 里写明的限制
   （`docs/evaluation-data-v040/README.md` §四）。
   ⇒ 需要架构审查官把 A6 的 probe 改成行为级；本轮已用
   `evaluation/check_gate_behavior.py` + pytest 行为级回归测试补上。
6. **本规范只管门禁，不管指标定义**。`v040-效果测量方案.md` §3.1 的主/辅指标定义
   与 §3.4 的交错实验设计仍是重建基线的前置条件。
